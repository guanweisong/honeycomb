# 账号安全管理扩展设计

## 背景

项目已使用 Better Auth 管理用户名密码、OAuth、Passkey 和会话。现有账号安全页只能管理 Passkey、密码和有效会话，缺少 OAuth 关联账号管理及历史安全事件查询。

## 设计

账号安全页新增“关联账号”和“登录历史”两个 Tab。关联账号使用 Better Auth 原生的 `listAccounts`、`linkSocial` 和 `unlinkAccount`，并关闭隐式 OAuth 关联，所有绑定必须由用户主动发起。解绑使用项目封装的 Dialog，并保留最后一个认证方式保护。

登录历史新增独立表，记录成功登录、失败登录、主动退出和退出其他设备，保存事件、认证方式、IP、User-Agent 和整数毫秒时间。认证成功通过 session hook 记录，认证失败通过认证 Route Handler 响应记录，查询接口只返回当前用户最近 50 条记录。

## 边界

本次不实现二次验证、邮箱修改、账号删除、地图定位、设备指纹或风险评分。日志不保存密码、token 或原始敏感登录输入。

## 部署与回滚

先迁移新增历史表，再部署认证配置和页面。若需回滚，可隐藏新增 Tab 并回退应用代码，历史表保留，不影响现有认证数据。
