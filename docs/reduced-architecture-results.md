# 减法版架构实施与验收

更新日期：2026-10-20。本文是实施结果索引，不复制长期行为规范。代码完成不等于已经合并或完成生产环境验收。

## 已实现范围

- 文章：正文、翻译及四类关联原子保存，版本冲突和删除保护，资源关联的有限创建去重；严格输入与显式 `removeLocales`，随机推荐使用单个公开快照。
- 页面：双语保存合同不变，增加独立编辑版本、创建恢复、版本化删除和失败/未知结果反馈。
- 菜单与设置：整体快照的条件保存、当前账户复核、一致读取；菜单目标删除同步提升版本，孤立菜单有明确移除入口。
- 编辑体验：保留本地草稿、保存中后续输入和账户隔离。提交成功与刷新失败分开；未知结果不透明重放；已确认状态不由旧查询覆盖。
- 账户安全：保持 BetterAuth 协议，分别处理已提交、刷新失败和结果未知，防止重复或过期响应；Passkey 刷新按实际 SDK atom 错误合同判断。
- 媒体：临时直传、单次候选复制、最终字节完整解码与 READY 条件绑定；最小生命周期、恢复线索、人工核对、已知引用保护；删除未知历史引用须明确确认。没有新增任务平台、全量引用登记或私有媒体网关。
- 原有目录整理、审查修补、非法 tag/author 路由保护保持在同一 PR。公开反馈宿主与提交前 hydration 保护已补回归。
