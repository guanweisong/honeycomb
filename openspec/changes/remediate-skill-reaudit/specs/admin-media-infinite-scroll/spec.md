## ADDED Requirements

### Requirement: 分页协调依据查询身份而非内容相等

媒体列表 MUST 排除上一页 placeholder，并按当前查询页协调有效结果；MUST NOT 因为相邻页 ID 相同而拒绝有效结果。展示结果按 ID 去重，完成协调后释放该页加载锁。

#### Scenario: 相邻分页返回相同ID

- **WHEN** 并发插入导致合法下一页内容ID与上一页相同
- **THEN** 查询按真实页身份完成协调并释放加载锁，不永久显示加载更多

## MODIFIED Requirements

### Requirement: 媒体变更后必须重置分页
上传或删除媒体成功后，系统 MUST 丢弃后续页并重新请求第一页，同时保留现有的选择和通知行为。已有第一页可在刷新期间或失败时保留；结构共享返回同一数据引用时 MUST NOT 清空可见媒体。

#### Scenario: 上传成功
- **WHEN** 媒体上传成功
- **THEN** 系统重置到第一页并刷新媒体列表

#### Scenario: 删除成功
- **WHEN** 媒体删除成功
- **THEN** 系统清除当前选择、重置到第一页并刷新媒体列表

#### Scenario: 第一页刷新未改变数据
- **WHEN** 刷新成功但查询缓存复用原数据引用
- **THEN** 已有第一页仍可见，不因等待新的引用而成为空列表
