## ADDED Requirements

### Requirement: 公开评论正文与目标可见性使用同一读取快照

系统 MUST 在读取公开评论正文的同一 SQL 查询中校验目标仍已发布；文章及 CUSTOM 评论还 MUST 校验目标评论开关启用。此前的目标策略检查 MUST 保留稳定的错误语义，但 MUST NOT 单独授权后续快照中的评论正文。

#### Scenario: 前置检查后目标撤回并产生新评论文本

- **WHEN** 目标在前置检查后被撤回，且已有评论在撤回后被修改
- **THEN** 后续公开列表不返回该文本，计数也不包含它

#### Scenario: 前置检查后关闭文章评论

- **WHEN** 文章或 CUSTOM 目标在前置检查后关闭评论
- **THEN** 后续公开列表不返回该目标评论

#### Scenario: 目标持续公开可评论

- **WHEN** 目标在读取快照中仍满足公开评论策略
- **THEN** 正常公开评论、屏蔽回复建树与计数契约保持不变
