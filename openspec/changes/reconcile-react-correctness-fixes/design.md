## 背景

当前基线 ebefd590 已完成简单 feature/server 架构、版本化编辑、媒体与 CI 改造。旧提交 33432b94 作为恢复点保存；对当前代码逐项映射，不整体移植。

## 目标与非目标

目标：修复仍存在的草稿丢失、过量传输/订阅、边界泄漏及查询错误，并保持当前可见行为。非目标：恢复旧层次、回退迁移、修改删除限制/媒体状态、全仓格式化、部署或生产数据修改。

## 决策

- 表单默认值属于挂载会话；异步首次初始化与显式 reset 保留，记录/模式/开关变化创建新会话。已版本化 setting 表单不替换。
- 控件动态加载与稳定 calendar 槽位保留当前日期范围、locale、媒体 provider；工具栏独立订阅。公开分页使用观察器与请求/错误门禁，不改卡片或菜单视觉。
- 公共列表 schema 从当前权威模型派生，运行时选择所需字段；保持当前有序 ID 分页、PUBLISHED 二次检查与同一次 hydration 元数据/翻译快照。后台和详情仍完整。
- 翻译时间戳、标签筛选、用户名同步只改当前所属 server 函数。用户名继续保留大小写，限制与实际 auth 相同；无数据回填。设置 CAS 与已修复管理员保护不动。
- 安全修改扩展当前错误分类与 HTTP 边界，不重建 Sentry、业务错误或日志协议。邮件使用请求取消期限，不新增重试。
- E2E 只增加现有命令的参数/输出预检，复用当前独占库标记与显式初始化，保留 Playwright 自身生命周期和现有 CI 两个作业。拒绝旧自定义进程树 runner 方案。
