## 总体方案

以 OpenSpec 作为唯一需求和设计事实来源。活动变更和新增变更文档统一使用中文，代码符号、API、路径、命令和必要技术术语保留原文。

删除 `docs/superpowers` 下未被工程引用的设计文档，避免维护者误以为存在第二套 SDD 流程。历史 OpenSpec 归档文档保留其版本记录；本次优先治理活动变更和当前工作流入口。

组件目录测试增加以下检查：

- `components` 下的组件入口必须是 `组件名/index.tsx`；
- 组件目录名必须使用大驼峰；
- 每个组件入口必须有同目录 `index.test.tsx`；
- 组件目录内不得存在非入口 `.tsx` 组件文件。

非组件模块采用渐进式目录规则：单文件模块使用 `queries/foo.ts` 与 `queries/foo.test.ts`；只有存在多个相关文件时，才升级为 `queries/foo/index.ts` 目录模块。
