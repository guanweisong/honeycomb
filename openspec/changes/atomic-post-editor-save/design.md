## 目标和非目标

目标是文章的一次完整编辑提交和明确的失败结果，保留原权限、语言、状态与 publicSync 行为。非目标是微服务、通用 Repository、全局回执、可靠邮件、缓存替换、全仓目录搬迁和生产操作。

## 协议

共享 PostFieldsSchema 只含原有表单字段。create 额外要求 creationToken UUID，允许 movieActorIds、movieDirectorIds、movieStyleIds、galleryStyleIds 四个有界去重数组；update 额外要求 id、expectedVersion。更新省略角色不改，[] 清空；null 保持原有可空字段语义，不扩大现有翻译删除协议。必须存在实际修改，只有版本不是修改。

删除使用有界 items 数组，每项 id/expectedVersion；同批任一冲突整批回滚。旧写请求缺少版本被拒绝并要求刷新，不能自动采用最新版本。updateTags 仅有内部编辑器调用，迁移后删除，不留下绕过版本的独立关联写路径。

create/update 返回最小 {id,version,publicSync}。creationResult 为当前主体查询其 creationToken 的只读入口，仅返回已创建资源的 id/version 或无法确认，不把查无记录当作从未创建的证明。

## 数据和一致性

post 增加非负整数 version，默认 0；nullable creationToken/creationInputHash 与 authorId 组成资源存续期内去重。唯一索引为(authorId,creationToken)，原始规范化创建输入摘要不随后续编辑变化。新字段与索引采用下一条前向迁移，保留历史数据与既有迁移。

命令接收服务器提供的 actorId，在写事务读取当前 ENABLE 用户与角色，复用 can/Permission。权限检查不能仅存在 router。新建先验证权限、查同主体同令牌与摘要，相同返回当前安全结果，不同冲突；唯一约束处理并发。更新在同一事务读取当前状态和版本、校验转换、按 id/version 条件写入，原子更新翻译及指定关系。数据库外副作用只在提交后执行一次；回滚不失效缓存。重放可重新尝试失效，但不重写业务记录。

所有文章编辑路径递增同一版本，浏览量不递增。标签删除级联关联、媒体删除置空封面也需在既有事务内提升受影响文章版本，避免外部写入绕过编辑快照。跨 feature 变更仅限这些真实影响，不扩展其他业务规则。

read DTO 显式白名单，不 spread 带私有创建字段的数据库行；新增版本与翻译/关系必须来自同一个读取快照。关联查询后已不存在的记录不得由更早的行重建。公开缓存旧形状缺少版本时拒绝解码并回源，不默认补 version=0，不改变缓存体系。

## 编辑器

四类选择进入原有表单及草稿，而不是四套额外独立状态。MultiTag 仅创建全局标签及本地选择，不写文章关系；无权管理关系时不发送相应字段。发布和撤回沿统一提交。

编辑基线版本独立于后台 refetch；脏表单不会因为新查询结果自动取得新版本。成功提交推进基线版本，即使刷新失败；只确认提交快照，保留随后编辑。冲突、确定失败和结果未知区分，均不悄悄覆盖或重复创建。

创建仅保留一个账户隔离、同步持久化的冻结尝试（原始规范化 payload 与 token），在首次网络发送前写入，沿用现有草稿文件中的窄 helper，不建立通用 checkpoint API。恢复先查询 creationResult；未知时不自动创建。已知校验失败后修改内容为新意图；未知尝试不能换 payload 继续使用旧 token，亦不能自动换 token。资源删除后无永久去重保证，明确提示人工核对。

## 验证和迁移

先证明原子回滚、版本冲突、真实权限、创建并发去重及私有字段不泄露，再接编辑器。覆盖旧缓存、关联读快照、标签和封面外部变更、提交后编辑、账户切换和草稿恢复。所有 DB 验证遵守 test-database-safety；最终运行类型、Lint、完整单元覆盖率、进程、隔离构建、严格规格及可运行浏览器验证，记录未执行项。

schema 先扩展，客户端/服务端统一切换；不双写旧新流程。旧代码不理解版本时不可安全继续写，回滚需禁写或兼容补丁。不得把代码回滚等同于数据恢复。
