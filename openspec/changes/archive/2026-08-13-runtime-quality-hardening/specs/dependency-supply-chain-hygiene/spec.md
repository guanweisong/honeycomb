## MODIFIED Requirements

### Requirement: 直接依赖漏洞修复和开发工具隔离
系统 MUST 使用不受已知公告影响的直接运行时依赖版本，并将只在开发中调用的组件生成 CLI 保留在开发依赖中。系统 MUST 复核锁文件中的直接及生产可达传递依赖；严重公告必须被升级消除，高危公告必须被升级消除或具有记录原因、影响范围和到期复核日期的例外。

#### Scenario: 安装生产依赖
- **WHEN** 生产部署安装依赖
- **THEN** 不安装 `shadcn` CLI，且富文本清洗、数据库、国际化和 CSS 直接依赖使用已修复版本

#### Scenario: 审计发现生产可达高危公告
- **WHEN** 依赖审计报告直接或生产可达的 high 或 critical 公告
- **THEN** 变更必须升级至已修复版本，或提交包含原因、影响范围和到期日期的审计例外
