## 为什么

逐文件审查发现少量通用机制重复实现，维护成本主要来自媒体分页状态和测试装配，而不是缺少更多库。本变更优先复用已安装依赖与平台能力，并保留权限、事务、缓存及异步会话契约。

## 变更内容

- 保留媒体按页查询并修复 reset 竞态；统一表单提交状态与编辑器状态订阅。
- 使用官方 UTCDateMini；以 RTL/DOM 小范围简化 React 测试装配。
- 服务端分组、受控 Promise、测试超时桥接及脚本解析/扫描复用现有能力。
- 不改变预取导航 pending 与符号链接扫描政策；无法等价替换的候选明确暂缓；infinite query 默认重取全部历史页，亦不强行引入。

## 能力

### 新增能力

- `generic-capability-reuse`：约束通用机制复用时的行为等价与测试证据。

### 修改能力

无。既有业务输入、数据库结构与公开输出协议不变。

## 影响

涉及媒体管理 hook、DynamicForm、富文本编辑器、UTC 格式化、服务端分组与测试/开发脚本。新增生产依赖 @date-fns/utc，开发依赖 @testing-library/react 和 @testing-library/dom；不引入 user-event/jest-dom，不迁移数据库，不发布或合并分支。
