## ADDED Requirements

### Requirement: 阅读路径直接且边界明确

工程 SHALL 删除无独立职责的文章命令转发和纯别名展示文件，同时保留授权、应用编排、领域不变量与仓储边界。

#### Scenario: 阅读文章更新

- **WHEN** 开发者从文章 router 追踪更新操作
- **THEN** 可以直接进入实际命令编排，领域检查和仓储写入保持既有顺序与语义

### Requirement: 展示与数据契约分离

工程 SHALL 将展示标签和选项放在 UI，将当前用户运行时放在共享后台 UI，并禁止评论 UI 依赖 app 层函数类型。

#### Scenario: 跨模块消费契约

- **WHEN** 其他模块导入共享数据契约
- **THEN** 契约来源是所属模块的权威模型，不引入 React Provider 或当前用户网络查询

#### Scenario: 展示选项迁移

- **WHEN** 管理界面读取状态或类型选项
- **THEN** 所有选项值、显示名称和排列顺序与迁移前完全一致
