## 背景

Header 已把菜单领域数据转换为 MenuLocalEntity 树；公开 Menu 当前递归渲染子项。树结构仍服务分类路径、面包屑与后台编辑，不应通过删除数据解决展示问题。

## 目标与非目标

目标是只渲染输入树的根级菜单，保留其顺序、标签和国际化 Link、分类祖先高亮与移动交互。非目标包括改动菜单领域契约、后台多级编辑器、数据库、路由和面包屑。

## 决策

- 保留 Header → Menu 的调用及既有 MenuLocalEntity、MenuItem 权威契约；在 Menu 内直接映射根级链接，移除递归分支与子项展开状态。
- 不采用 CSS 隐藏子项，以免保留不需要的 DOM、交互和维护成本；不将子项提升为一级链接，因为这会改变用户的一级导航。
- 不修改权限、服务端或持久化层，无数据迁移。继续使用完整菜单计算祖先高亮。

## 风险与取舍

- 移除嵌套 Escape 处理可能误删移动端关闭行为 → 独立验证移动端 Escape 关闭及焦点回到开关，并保留导航后关闭、外部点击关闭测试。
- 历史测试要求子菜单展开 → 替换为深层输入仅产生一级链接的回归测试，保留后台菜单及面包屑的层级测试。

## 验证与交付

先证明新回归在原实现失败，再删除递归实现并运行相关测试。全量测试、类型、Lint、规格和构建由本次集成流程验证，未完成项保持待办；不以局部通过代表生产验证。
