## 背景

共享后台 UI、后台入口组合和评论限流各有实际所有者。当前文件归属混合，使枚举与配置、技术能力与业务策略难以区分。

## 变更内容

- admin 的状态工具、配置、三个枚举和草稿职责就近归组，完整场景与布局协议保持。
- 后台查询客户端及认证审计适配归 app；评论入口显式持有 5/min 和 fallbackLimit=5。
- 删除纯 Drizzle 转发壳和旧 IP 转出口，保留全部 HTTP 与限流断言。
- auth-client 已独立提交；本变更也不涉及 PWA、sitemap、auth.ts 架构或新抽象。

## 能力

### 新增能力

- owned-module-locations：约束明确所有权与迁移等价验证。

### 修改能力

无。

## 影响

共享后台 UI 及消费者、app 组合、评论入口和两个无额外职责出口；不改变样式、鉴权、草稿、查询重试、限流数值或失败策略。admin 和适配整理分别提交，最终共同完整回归后另行授权发布。
