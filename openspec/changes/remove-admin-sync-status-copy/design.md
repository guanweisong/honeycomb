## 背景

全局搜索确认常驻提示仅由 MenuPageShell 和 SettingClient 的两个段落直接渲染，无共享状态组件。菜单脏状态由 useMenuTreeEditor 管理，设置由 useSettingSnapshotForm 管理。

## 目标与非目标

删除常驻同步与未保存文案，不改变编辑器状态、按钮禁用条件、保存生命周期或任何恢复保护。冲突、未知结果、刷新失败与草稿恢复提示不属于本次删除范围。

## 决策

直接移除两个展示段落，不引入隐藏样式、空状态组件或新抽象。保留两个钩子和全部消费者逻辑；相比删除脏状态，纯展示修改能保持原有保护和提交行为。

## 风险与取舍

旧测试依赖文案观察脏状态 → 改为断言保存按钮可用性与输入保留，同时新增文案不存在的回归。无数据迁移、权限或依赖变更；回退仅恢复展示段落。
