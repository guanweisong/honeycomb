## MODIFIED Requirements

### Requirement: 站点表单保留用户编辑
前端 MUST 保留脏输入和保存期间的新输入，并区分冲突、未知结果、确定提交及提交后刷新失败。未知结果 MUST NOT 自动重试。

#### Scenario: 背景刷新与保存期间继续编辑
- **WHEN** 查询刷新或较早保存返回时仍有新输入
- **THEN** 输入保持且内部仍标记未保存，不被返回快照覆盖

#### Scenario: 保存成功但刷新失败
- **WHEN** 写入已经确认提交而刷新失败
- **THEN** 显示已保存待刷新，不将其报告为保存失败或自动重发

#### Scenario: 切换账户或卸载
- **WHEN** 旧保存返回前编辑器身份改变或卸载
- **THEN** 旧响应不得修改新表单状态

#### Scenario: 常驻同步状态不显示
- **WHEN** 管理员查看菜单或设置表单，或编辑后产生未保存输入
- **THEN** 页面 MUST NOT 展示「已与服务器同步」「有未保存的更改」常驻文案，保存可用性、恢复与保护行为保持不变
