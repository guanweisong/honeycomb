## Why

文章和独立页面详情目前只依赖运行时动态参数，生产环境直接请求时需要等详情数据完成后再响应。为当前已发布内容生成构建参数，可以让构建产物预先包含常用详情页面，同时保留新内容的按需访问能力。

## What Changes

- 为文章详情和独立页面详情按已发布 ID 生成 `zh/en` 构建路径。
- 继续允许未在构建清单中的详情 ID 在运行时解析，完整枚举不成为路由正确性的前提。
- 在详情 URL 不存在可生成的已发布 ID 时提供无效占位参数，由现有 ID 校验返回 not-found。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `instant-navigation`：允许已发布详情 ID 用于构建预渲染，同时要求未枚举 ID 仍可运行时访问。

## Impact

- 影响文章和独立页面详情路由、构建时公开 ID 查询及即时导航规范。
- Vercel 构建需能访问该部署目标配置的数据库环境变量；评论和友情链接等请求时边界保持独立。
