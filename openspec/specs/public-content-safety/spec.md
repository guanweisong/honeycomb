## Purpose

定义数据库富文本、JSON-LD 脚本上下文和公开内容缓存失效的统一安全边界，防止历史内容触发存储型脚本注入，并禁止客户端控制任意缓存路径。

## Requirements

### Requirement: 公开富文本必须在展示边界清洗

系统 MUST 在数据库富文本进入 React HTML 解析器之前使用唯一清洗策略移除脚本、事件处理器和危险 URL，并保留允许的排版及媒体标记。

#### Scenario: 历史内容包含危险标记

- **WHEN** 公开文章或页面读取到包含脚本、事件属性或 `javascript:` URL 的历史 HTML
- **THEN** 渲染输出不包含可执行内容，且正文允许标签继续显示

### Requirement: JSON-LD 必须安全序列化

系统 MUST 在 JSON-LD 写入原生脚本标签前转义能够终止脚本上下文的字符，同时保持合法 JSON 语义。

#### Scenario: 标题包含脚本闭合串

- **WHEN** 文章标题或摘要包含 `</script>`
- **THEN** HTML 中的 JSON-LD 不出现原始 `<` 字符，解析后的结构化数据仍保留原值

### Requirement: 缓存刷新输入必须结构化受限

公开调用方 MUST NOT 提交缓存路径；写操作成功后，服务端 MUST 根据已校验的内容类型和内容标识自行构造允许刷新的公开路径。

#### Scenario: 评论提交成功

- **WHEN** 公开调用方成功创建评论并刷新界面
- **THEN** 缓存失效由服务端根据评论目标执行，客户端不存在可提交根路径或管理路径的刷新接口
