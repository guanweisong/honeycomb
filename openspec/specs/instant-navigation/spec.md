# 即时导航 Specification

## Purpose

定义公开博客与后台路由在客户端导航时提供即时页面外壳、按需执行请求时检查，以及完整预取博客内容的行为。

## Requirements

### Requirement: 每个面向用户的 App Router 目标都提供即时且安全的页面外壳

所有可通过客户端导航访问的公开博客和后台路由 MUST 渲染静态或缓存的页面外壳，以便导航时立即显示。对于构建时已发布并由详情路由生成的文章和独立页面，直接刷新时的首个预渲染输出 MUST 同时包含共享 Header、对应正文和 Footer；这些内容 MUST NOT 先以只有头尾的空壳显示，再由正文撑开布局。构建时未枚举的文章或页面 ID MUST 仍可在运行时解析；开发态 MAY 在未枚举参数和正文解析期间显示局部 Suspense fallback，生产环境的完整页面及 URL 预取响应 MUST 包含公开正文或 not-found 结果，后续请求可复用缓存。其他请求时 API、依赖路由的未缓存读取和授权检查 MUST 放在路由局部的 Suspense 边界后；文章详情页的猜你喜欢查询遵循下一 Requirement 所述例外。应用 MUST NOT 使用 `instant = false` 让路由避开即时导航验证。fallback MUST NOT 暴露后台私有内容或绕过授权。

#### Scenario: 刷新构建时已生成的公开详情

- **WHEN** 访客直接刷新构建时已生成的文章或独立页面 URL
- **THEN** 首个预渲染输出同时包含 Header、详情正文和 Footer，不先显示缺少正文的共享页面外壳

#### Scenario: 首次访问构建时未列出的公开详情 ID

- **WHEN** 访客直接刷新或导航访问构建时未生成的文章或页面 ID
- **THEN** 开发态路由可以通过局部 Suspense 解析 URL 参数；生产环境完整页面及 URL 预取响应包含详情正文或 not-found，后续访问复用缓存

#### Scenario: 后台页面的请求级检查尚未完成

- **WHEN** 后台目标页面在导航期间需要执行会话或能力检查
- **THEN** 检查访问权限期间显示不含敏感信息的 fallback，只有授权成功后才渲染受保护页面内容

#### Scenario: 当前用户没有访问后台目标页面的能力

- **WHEN** 请求级路由检查发现已认证用户无权访问目标页面
- **THEN** 使用现有的禁止访问重定向或页面，目标页面的受保护内容不得出现在页面外壳或 fallback 中

### Requirement: 博客站内链接完整预取目标内容

博客共享站内链接 MUST 默认使用 `prefetch=true` 预取目标 URL 的缓存内容，同时 MUST 保留调用方显式指定的 `false`、`auto` 或 `null`。标签与搜索结果 SHALL 直接复用共享链接的默认完整预取策略，不增加自定义意图状态或事件处理；该简化允许更多提前请求；文章主要入口、菜单和语言切换 MUST 保留原策略。生产环境中的文章与独立页面详情预取结果 MUST 包含对应公开正文，菜单分类列表预取结果 MUST 包含 URL 对应的首屏文章卡片，点击导航 MUST 能复用这些数据。文章详情页的猜你喜欢查询 MUST 在文章详情 RSC 结果完成前执行并渲染；该查询 MAY 延迟完整文章 RSC 预取响应，但最终预取响应 MUST 保留公开文章正文，并在查询成功且有推荐项时包含推荐模块。推荐查询失败 MUST 只省略推荐模块，不得使文章正文丢失。评论和友情链接等其他请求时数据 MAY 保持独立动态读取，MUST NOT 阻塞正文预取；后台私有数据 MUST NOT 进入公开预取结果。后台导航链接 MUST 保留 `auto`；单条已授权详情的意图数据预取不等于强制完整路由预取，MUST NOT 绕过服务器权限。

#### Scenario: 默认博客站内链接进入视口

- **WHEN** 生产环境中未覆盖策略的博客站内链接变为可见
- **THEN** Next.js预取目标URL的缓存内容

#### Scenario: 从列表预取文章正文

- **WHEN** 生产环境中的文章链接进入视口且完整预取在点击前完成
- **THEN** 对应 RSC 预取响应包含公开文章正文，点击后直接呈现该文章

#### Scenario: 从菜单预取独立页面正文

- **WHEN** 生产环境中的独立页面链接进入视口且完整预取在点击前完成
- **THEN** 对应 RSC 预取响应包含公开页面正文，点击后直接呈现该页面

#### Scenario: 从菜单预取分类列表首屏

- **WHEN** 菜单中的分类链接完成完整预取
- **THEN** 对应 RSC 预取响应包含该 URL 筛选后的首屏文章卡片，点击后直接呈现列表

#### Scenario: 文章推荐查询完成后预取文章详情

- **WHEN** 文章详情完整预取期间，猜你喜欢查询仍在进行
- **THEN** 完整 RSC 预取响应在推荐查询结束后完成，并包含公开文章正文以及成功查询得到的推荐模块

#### Scenario: 其他请求时数据不阻塞正文预取

- **WHEN** 文章或独立页面正文预取期间，评论或友情链接仍需请求时读取
- **THEN** 这些数据在独立边界中加载，正文仍包含在目标 URL 的预取响应中

#### Scenario: 推荐查询失败时保留文章正文

- **WHEN** 文章详情预取期间猜你喜欢查询失败
- **THEN** 完整 RSC 预取响应仍包含公开文章正文，且只省略推荐模块

#### Scenario: 标签与搜索结果复用默认完整预取

- **WHEN** 标签或搜索结果渲染共享链接
- **THEN** 链接使用默认prefetch=true，由框架调度预取；导航不等待预取完成

#### Scenario: 调用方禁用预取

- **WHEN** 调用方显式传递false或null
- **THEN** 封装原样保留该值而非回落为true

#### Scenario: 后台菜单链接进入视口

- **WHEN** 已认证用户看到后台菜单链接
- **THEN** 链接按auto预取页面外壳，不强制完整预取私有路由数据

### Requirement: 动态语言和内容参数无需完整构建时枚举

根 `[locale]` 和列表 slug MUST NOT 依赖 `generateStaticParams()` 枚举完整参数。文章归档 ID 与独立页面 ID MAY 使用 `generateStaticParams()` 预生成构建时已发布内容的路径；该枚举 MUST 使用已发布内容的轻量 ID 投影，并生成全部支持语言的路径。文章和页面详情路由 MUST NOT 将完整 ID 枚举作为路由正确性的前提；构建后新增或未枚举的 ID MUST 仍可在运行时解析。空内容时，生成器 MUST 按 Cache Components 非空参数要求返回不会暴露内容的无效占位 ID，并由既有 ID 校验处理为 not-found。列表详情路由 MUST 在需要运行时解析参数或数据时保留局部 Suspense 边界，使共享静态页面外壳可复用；文章和独立页面详情路由 MAY 在开发态对未枚举参数保留局部 Suspense 边界。详情路由在构建时已生成的公开 ID MUST 在预渲染输出中包含正文；未枚举 ID MUST 可在运行时解析，生产环境完整页面及 URL 预取响应 MUST 包含正文或 not-found。

#### Scenario: 构建当前已发布详情路径

- **WHEN** Next.js 构建应用且数据库包含已发布文章或独立页面
- **THEN** 每个已发布 ID 都为全部支持语言生成详情路径，并使用原有公开详情读取生成页面内容

#### Scenario: 构建后访问新增详情 ID

- **WHEN** 访客访问未在构建参数中列出的文章或页面 ID
- **THEN** 路由仍在运行时解析该 ID，完整页面响应呈现公开内容或 not-found；URL 预取完成后包含正文，后续访问可复用运行时生成的缓存结果

#### Scenario: 构建时没有已发布详情

- **WHEN** Next.js 构建应用且没有已发布文章或独立页面
- **THEN** 生成器提供无效占位 ID 以满足非空参数要求，详情路由由既有 ID 校验返回 not-found
